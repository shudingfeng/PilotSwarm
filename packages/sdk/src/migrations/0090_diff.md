# Migration 0090: Dispatcher delegation opt-in

Adds `users.allow_dispatcher_delegation BOOLEAN NOT NULL DEFAULT false`: a
user's consent to the deployment's dispatcher (the application principal named
by the portal's `DISPATCHER_SP_OBJECT_ID`) creating sessions for them and
ending the sessions it created. Every existing row reads `false`; the column
has a constant default, so adding it rewrites no data.

It is a column of its own because the portal replaces `users.profile_settings`
wholesale on every preference save: an opt-in kept in that document would be
lost by any unrelated save.

## New stored procedures

Both are `CREATE OR REPLACE` of **new** names. The migration replaces no
existing procedure, so a different final number for it changes nothing else.

### `cms_set_user_dispatcher_delegation(provider, subject, email, display_name, enabled) → BOOLEAN`

Registers the user through `cms_register_user` (so a first write creates the
row and email/display name keep their update-on-sighting rule), then replaces
the flag and returns the stored value. `NULL` is refused.

### `cms_get_user_dispatcher_delegation(provider, subject) → BOOLEAN`

The stored flag, or `false` for an unknown user.

## What does not change

No access procedure reads the flag. `cms_get_session_access`, the list
procedures and `session_shares` are untouched: the portal checks the owner's
flag itself, on every path that honours a share, when the caller is the
dispatcher. Turning the flag off therefore keeps the dispatcher's targeted
shares, and turning it back on restores its access to the same sessions.

## Callers

- `PgSessionCatalog.getUserDispatcherDelegation` /
  `.setUserDispatcherDelegation` (`cms.ts`).
- `PilotSwarmManagementClient.getMyDispatcherDelegation` /
  `.setMyDispatcherDelegation`, and the `GET` / `PUT /api/v1/me/dispatcher-delegation`
  operations, which the portal binds to the signed-in caller.
- The portal's authorization gate, listings and session subscriptions, which
  read the owner's flag when the caller is the dispatcher.
